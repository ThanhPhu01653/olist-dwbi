# D5 – Customer Experience

*Loại: Thống kê. Dựng theo `powerbi/model.md`; công thức DAX ở `powerbi/measures.md`. Cây phân tích: `huong-dan/05-nghiep-vu-nhap.md` mục 6 (hình `figures/3-2-7_cay_phan_tich_D5.png`).*

## 1. Mục tiêu

Hiểu trải nghiệm khách hàng: điểm đánh giá, ảnh hưởng của giao trễ, cơ cấu thanh toán, khách quay lại.

## 2. Câu hỏi dashboard trả lời

- Điểm review TB bao nhiêu, bao nhiêu % tiêu cực?
- Giao trễ làm điểm review giảm thế nào?
- Khách thanh toán bằng gì, trả góp bao nhiêu kỳ?
- Bao nhiêu khách quay lại; phân khúc RFM và cohort?

## 3. KPI và measure dùng

| Measure | Ý nghĩa |
| --- | --- |
| **Avg review** | điểm review TB |
| **% negative** | % review tiêu cực (≤ 2 điểm) |
| **Avg review - late delivery / on time** | điểm TB đơn trễ / không trễ |
| **Payment value / Payment share** | giá trị và tỷ trọng thanh toán |
| **Avg installments** | số kỳ trả góp |
| **Repeat customer rate** | khách quay lại (≥ 2 đơn) |

Mã DAX đầy đủ từng measure: `powerbi/measures.md`. Màu cảnh báo: các measure `Color …` ở mục 9 của file đó.

- Cohort: drill từ năm xuống tháng

## 7. Conditional formatting

- Card review: theo `Color Avg review`, `Color % negative`
- Cohort: **color scale** trắng → xanh đậm
- Cột `avg_score` theo nhóm trễ: màu đỏ nếu < 3

## 8. DAX đặc biệt

**Tách điểm review theo giao trễ**

```dax
Avg review - late delivery = CALCULATE ( [Avg review], fact_review[is_delivered] = 1, fact_review[delivered_late] = 1 )
Avg review - on time = CALCULATE ( [Avg review], fact_review[is_delivered] = 1, fact_review[delivered_late] = 0 )
```

**Khách quay lại**

```dax
Repeat customers =
COUNTROWS ( FILTER ( VALUES ( dim_customer[customer_unique_id] ), CALCULATE ( COUNTROWS ( fact_order_fulfillment ) ) >= 2 ) )
```

## 10. Insight gợi ý (có số thật, để viết vào báo cáo và slide)

1. **Điểm review tụt theo mức trễ: 4,29 (giao sớm) → 3,29 (trễ 1–3 ngày) → 2,10 (4–7) → 1,70 (trên 7 ngày)**; % tiêu cực tăng 9,2% → 79,2%.
2. Đơn trễ chỉ chiếm 6,5% số review nhưng tạo **27,4% số review tiêu cực** (4.000/14.575).
3. Thẻ tín dụng chiếm **78,3% giá trị thanh toán**, boleto 17,9%; thẻ trả góp TB 3,5 kỳ và 66,9% giao dịch thẻ trả góp nhiều kỳ.
4. Chỉ **3,12% khách mua lại** (2.997/96.096); cohort cho thấy tỷ lệ quay lại sau 1 tháng chỉ ~0,5%.
5. RFM: 94.983 khách; "Ngủ đông" 36.957 và "Khách mới" 36.752 chiếm gần hết; chỉ 129 khách Champions.
